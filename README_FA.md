# بسته افزودن نمونه‌کارهای سئو و نویسندگی به پورتفولیوی مرتضی احمدی

## مهم: این فایل «کل سایت جدید» نیست
این بسته برای **افزودن بدون حذف پروژه‌های قبلی** طراحی شده است. به‌هیچ‌وجه ZIP این بسته را به‌تنهایی با Netlify Drop روی سایت فعلی منتشر نکنید، چون ممکن است فایل‌های فعلی سایت را جایگزین کند. ریشهٔ بسته عمداً index.html ندارد.

آدرس پورتفولیو: https://sparkling-marzipan-d8432e.netlify.app/

## محتوای بسته
- `writing/index.html` — صفحه فهرست آثار نویسندگی
- `writing/backlinks-vs-referring-domains/index.html` — متن کامل مقاله سئو، قابل خواندن روی وب
- `writing/revivio-marketing-copy/index.html` — متن کامل معرفی و فروش Revivio
- `downloads/` — نسخه‌های PDF همان آثار
- `assets/portfolio-writing.css` — استایل ریسپانسیو با نام‌گذاری مستقل
- `assets/portfolio-writing-addon.js` — تزریق یک بخش جدید پس از Selected Work در صفحهٔ اصلی، با حفظ پروژه‌های قدیمی
- `PREVIEW_Writing_Portfolio.html` — پیش‌نمایشِ گالری نمونه‌کارها؛ از طریق یک سرور محلی یا مرورگر باز کنید
- `EMBED_IN_EXISTING_INDEX.html` — دقیقاً دو تگ موردنیاز برای افزودن به صفحهٔ اصلی
- `merge_into_original.py` — ادغام خودکار در نسخهٔ اصلی سایت (فولدر یا ZIP)

## ادغام بدون تخریب (روش پیشنهادی)
1. اول از نسخهٔ اصلی سایت Netlify یک بکاپ بگیرید. فایل اصلی پروژه یا فایل ZIP استاتیک که قبلاً روی Netlify منتشر شده است لازم است.
2. اگر فایل ZIP نسخهٔ اصلی سایت را دارید، داخل ترمینال از ریشهٔ همین بسته اجرا کنید:

```
python3 merge_into_original.py /path/to/OLD_PORTFOLIO.zip --output /path/to/UPDATED_PORTFOLIO.zip
```

اگر پوشهٔ پروژه را دارید:

```
python3 merge_into_original.py /path/to/OLD_PORTFOLIO_FOLDER --output /path/to/UPDATED_PORTFOLIO.zip
```

3. ابزار فایل‌های اصلی را حفظ می‌کند، مسیرهای `writing` و `downloads` و `assets` جدید را اضافه می‌کند، و دو تگ لینک CSS و جاوااسکریپت را در index.html می‌نویسد. برای هر دو سناریو، خروجی یک ZIP کامل است که می‌توان آن را به‌عنوان سایت جدید در Netlify منتشر کرد.
4. فایل ZIP ادغام‌شده را منتشر کنید، نه ZIP افزونه را.
5. صفحه اصلی و مسیرهای مقاله را روی موبایل و دسکتاپ بررسی کنید. مخصوصاً فیلترهای قبلی پروژه‌ها و لینک PDF.

## اگر تغییر دستی در فایل پروژه ترجیح داده می‌شود
- کل پوشه‌های `writing` و `downloads` و فایل‌های `assets/portfolio-writing.*` را به ریشه پوشه انتشار فعلی اضافه کنید.
- دو تگ داخل `EMBED_IN_EXISTING_INDEX.html` را به `index.html` اصلی اضافه کنید.
- سایت کامل را مجدداً منتشر کنید.

## محدودیت این نسخه
سایت زنده با ابزار بررسی وب در این نوبت باز نشد و فایل‌های منبع اصلی سایت هم در دسترس نبودند. ساختار `Selected Work` و نام فیلترها از نسخه‌های قبلی گفتگو به دست آمده‌اند. افزونه عمداً کم‌تهاجمی است و فقط بخشی مستقل بعد از پروژه‌ها می‌سازد. تا قبل از دریافت source اصلی سایت، هم‌خوانی ۱۰۰٪ با رنگ، چیدمان و سیستم فیلتر فعلی را نمی‌توان تأیید کرد.
