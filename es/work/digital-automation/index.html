DIGITAL PRODUCT · BUSINESS AUTOMATION

Revivio y automatización operativa

Sistemas digitales para rastrear contactos, identificar canales y organizar datos de clientes.

Revivio — páginas para servicios

Concepto de páginas con servicios, precios, fotos, horario y contacto. Las rutas hacia WhatsApp pueden etiquetarse por origen; no es una promesa de generar clientes automáticamente.

Buscador europeo de leads

Aplicación con Google Places API para recopilar negocios, redactar mensajes locales y seguir contactos. Utiliza JavaScript, Netlify Functions y hojas de cálculo.

Decisiones editoriales

Los mensajes parten de datos comprobados y evitan inventar reseñas, tráfico o supuestas carencias de una empresa.

  • Google Places API y Netlify
  • Sheets y seguimiento de contactos
  • Mensajes multilingües revisados manualmente
